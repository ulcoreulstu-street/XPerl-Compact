# XPerl Compact

A compact, Sirus-focused edition of X-Perl UnitFrames for World of Warcraft 3.3.5a.

**Maintainer:** Ulcore@

## Project status

Initial repository setup. The source package and updater metadata will be added after the source tree is staged and validated.

## Credits and license

Based on X-Perl UnitFrames by Zek (Nymbia) and subsequent community-maintained code. This project retains the upstream GNU GPL v3 license; see `XPerl/LICENSE.txt` in the distribution.

## Compatibility

- World of Warcraft 3.3.5a (Interface 30300)
- Sirus client

## Important

Do not install this alongside another X-Perl installation. Back up your WTF settings before replacing an existing installation.
